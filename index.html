iPhone and iPad

Add the app to your home screen. It opens full screen with its own icon and works offline.

  1. Open the app in Safari, not Chrome
  2. Tap the Share button, the square with an arrow pointing up
  3. Scroll down and tap Add to Home Screen
  4. Tap Add
Why there is no file to download for iPhone. Apple only allows iPhone apps to be installed through the App Store, so an app file cannot be downloaded from a web page the way it can on Android. The home screen version above is the same app and it works offline.

Windows PC

A normal program. It never needs internet, not even the first time.

Download for Windows about 15 MB

  1. Download the file and unzip it
  2. Open the folder and double click vessel_inspection.exe
  3. Keep all the files together in the folder, otherwise the program will not start
Or install the browser version instead. Open the app in Chrome or Edge and click the install icon in the address bar. It becomes a desktop app with its own window and icon.
IP
Everything works offline once installed. All data stays on your own device.
